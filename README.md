# 🏥 MediCare Plus Hospital Website

A modern, fully responsive multi‑page hospital website built with **Bootstrap 5**, **AOS animations**, and vanilla **JavaScript**. It features two themes (dark/light), working signup/login with `localStorage`, a dedicated emergency page, and developer branding. Designed to look professional and trustworthy, this project is perfect for showcasing a medical institution’s online presence.

![Hero Screenshot](https://via.placeholder.com/1200x600?text=MediCare+Plus+Screenshot)

---

## ✨ Features

- **5+ Pages**: Home, About, Services, Doctors, Contact, Emergency, and Developer info.
- **Two Themes** (Dark/Light) with smooth toggle – persists in `localStorage`.
- **Working Signup/Login** – modals with validation, stored in `localStorage`.
- **Scroll Progress Bar** – indicates reading position.
- **AOS Animations** – elements fade, zoom, and slide on scroll.
- **Doctor Filter** – search doctors by name or specialty.
- **Animated Counters** – on Emergency page (response time, ambulances, etc.).
- **Fully Responsive** – mobile, tablet, desktop.
- **Developer Branding** – footer with profile, social links, and back‑to‑top button (Tanzeel Ahmed).
- **Contact Form** with real‑time validation (no backend – demo only).
- **Emergency Page** – ambulance info, staff, hospital stats.

---

## 🛠️ Technologies Used

- **HTML5** – semantic markup
- **CSS3** – custom styles with CSS variables for theming
- **Bootstrap 5** – layout, navbar, cards, modals, grid system
- **JavaScript (ES6)** – authentication, theme toggle, filter, counters, AOS init
- **AOS Library** – scroll animations
- **Font Awesome 6** – icons
- **Google Fonts** – Supreme Spihe, Zen Dot Z, DM Sans, Albert Sans

## 🚀 Getting Started

1. **Clone the repository** (or download the ZIP):
   ```bash
   git clone https://github.com/Tanzeel804/hospital-website.git
   ```
2. Open the folder and simply launch `index.html` in any modern browser.
3. No build tools or server required – everything runs locally.

---

## 🔐 Authentication Demo

- **Sign Up**: Create an account (name, email, password). Passwords are stored in `localStorage` (plain text for demo).
- **Login**: Use your credentials – the navbar updates to show a welcome message.
- **Logout**: Click “Logout” to end the session.
- Session persists across all pages.

---

## 🎨 Theme Toggle

Click the moon/sun icon in the navbar to switch between dark and light themes. Your preference is saved for future visits.
